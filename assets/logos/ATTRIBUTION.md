# Logos de marcas

Estes SVGs são usados apenas para identificação visual das marcas citadas no guia.

- Nike, adidas, New Balance e The North Face: [Simple Icons](https://simpleicons.org/). O projeto é distribuído sob CC0; consulte as diretrizes específicas de cada marca.
- Tommy Hilfiger, Vans, Gap, ASICS e Oakley: Wikimedia Commons, a partir dos arquivos de logotipo correspondentes.

As marcas e seus logotipos são propriedade de seus respectivos titulares.
